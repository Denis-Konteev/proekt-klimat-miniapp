# Proekt Klimat Uz — Mini App

Прототип мини-приложения для Telegram-канала Proekt Klimat Uz.

## Локальный запуск (не обязательно)
npm install
npm run dev

## Деплой
См. подробную инструкцию в PDF, которую прислал Claude.
Короткая версия: загрузить папку на GitHub → импортировать в Vercel → задать URL в BotFather.
